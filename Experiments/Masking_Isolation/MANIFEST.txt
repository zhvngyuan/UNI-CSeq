Masking_Isolation dataset
=========================
Purpose: isolate interrupt-masking modeling. One uncommented user assert per program.
Ablation (this experiment): goblint 4 + racebench 4 only, listed in testdirs.sh.
  Run with run_scripts/run_masking_ablation.sh (UNI-CSeq vs --ignore-masking).
C_rw_masked/ is kept on disk but is not in testdirs.sh and is not run.

Inclusion criteria (all four required)
--------------------------------------
1. Critical-section masking: disable_isr(n)/enable_isr(n) or n=-1 wraps the protected
   accesses. Not merely init() enable_isr(-1). Not main start disable/enable-all with
   no assert in between (blink3_main is the exception: the assert sits between them).
2. Assertion outcome depends on that masking: expected SAFE with masking modeled,
   UNSAFE if disable_isr/enable_isr are no-ops.
3. No independent real bug on that assertion (unmasked ISR still breaks it,
   uninitialized havoc, dead-branch unassigned locals, same-value writes, etc.).
4. Single-assert file: every other assert is commented out.

Expected verdicts
-----------------
mask   = UNI-CSeq as-is (disable_isr encoded); testdirs A+B only
nomask = unichecker.py --ignore-masking
Ground truth for A+B is SAFE, so a FALSE under nomask is counted as FP.

svp_simple_003_assert1
  kept assert: after disable_isr(1) and disable_isr(2), before enable_isr(1):
               assert(global_var2 == 0)   [racebench false-alarm site on var2]
  why: isr_1 writes var2=999 only after enable_isr(1). Without mask that write
       can fire during the assert.
  hygiene: global_var1/var2 initialized to 0 so CBMC havoc on uninitialized
           volatile cannot fail the assert independently of masking.

svp_simple_013_assert1
  kept assert: in isr_3, after if (flag1==1) var1=0x01: assert(var1==0x01)
  why: main starts with disable_isr(2/3). isr_3 cannot run until isr_2 sets
       flag1=1 and enable_isr(3). Without mask, isr_3 can run with flag1==0
       and the assert fails.
  hygiene: var1/var2 initialized to 0.

svp_simple_013_assert3
  kept assert: in main, assert(reader3 == reader4) on var2
               [racebench false-alarm site on var2]
  why: isr_3 writes var2 only if flag2==1; isr_2 clears flag2 before
       enable_isr(3). Without mask, isr_3 can write var2 between the two reads.
  hygiene: var1/var2 initialized to 0.

svp_simple_014_assert2
  kept assert: in isr_1 after disable_isr(3), two reads of var2 then
               assert(reader3 == reader4)
  why: isr_3 writes var2 only if flag2==1; isr_2 clears flag2 then enable_isr(3).
       With mask, isr_3 cannot run during the two reads until that enable.
       Without mask, isr_3 can write 0x09 between the reads.
  hygiene: original second assert was a copy-paste assert(reader1==reader2)
           after reading var2 into reader3/reader4. Changed that one
           expression to assert(reader3==reader4) to match the documented
           var2 false-alarm site. Without this fix the case would be excluded.

Excluded (failed a criterion)
-----------------------------
racebench 001: flag assert independent of mask; array assert is a documented real bug.
racebench 004: var1 is a real bug; var2 ISR writes the same value 0x22, so the
               assertion does not flip with/without masking.
racebench 013_assert2: var1 double-read is a documented real bug (isr_1 not masked).
racebench 014_assert1: var1 double-read is a real bug (isr_2 can still enable_isr(3)).
racebench 019: reader5 assigned only if condition3==0, which is initially 1;
               uninitialized reader5 can fail the assert without masking mattering.
racebench 020: main assert mixes a real bug / uninitialized reader; isr_1 assert
               is before flag=1 so isr_2 cannot yet write even without masking.
racebench 026 / 028 / 030: only some ISRs masked, or check-then-act still allows
               isr_1 to interfere (documented real bugs).
logger1, brake2, i2c_pca_isa_1/3, wdt_pci_2, i8xx_tco_3: no critical-section
               masking around an assertion.
brake1 / brake3: disable_isr(1) present but original file-level FALSE; cannot
               confirm the remaining assert has no independent failure
               (large loops / TRIGGER / other ISRs).
i8xx_tco_2: masked assert requires condition3==0 already; not "mask implies SAFE";
            original result TIMEOUT.
rw_benchmark / compare_with_intAbs_cbmc: masking stripped; experiment 1 already
               captioned "without interrupt masking". Not used here.
